# User-facing feature checklist (parity target)

Area `a32-user-facing-features`. Built from OpenWhisper's documentation, not from its code: `README.md`, `CONTRIBUTING.md`, every `docs/*.md` that describes behaviour, `docs/design/automation/design.md`, `docs/design/personalize/design.md`, and `CHANGELOG.md` read in full (through 2.8.92 plus Unreleased, 2026-11-12), plus the menu-building code of `ui_qt/main_window.py`, `ui_qt/system_tray.py` and the chapter list of `ui_qt/dialogs/settings_dialog.py`. The OpenWhisper checkout (`D:\coding\whisper_local`) was read-only. Benchmark and validation write-ups (`docs/benchmarks`, `typesafe-*-benchmark`, `codebase-performance-review`, `performance-implementation`, `testing-benchmark-repairs`, `parakeet-mlx-macos-validation`, `linux-asr-default`, `release-health` numbers) were skipped except where they state user-visible behaviour. `docs/design/` holds no `.md` directly; the two `design.md` files in its subfolders were read.

Line format: `- [ ] ID feature: precise behavior (source doc and heading; platforms)`.

Tags used inside lines:

- `[DROP]` only exists for a dropped local engine (faster-whisper/CTranslate2 Whisper, Moonshine, Qwen3-ASR, Parakeet MLX, Parakeet Unified/transcribe.cpp) or for the Python worker-process plumbing. Not ported; no depth spent.
- `[UNDECIDED:nemotron]` Nemotron Streaming (same NeMo runtime, so cheap to keep).
- `[UNDECIDED:cloud]` cloud/API transcription (OpenAI, Groq, own server). Text-model AI cleanup providers are NOT part of this tag; they are mapped normally.
- `[UNDECIDED:remote]` remote-computer engine (host/client, pairing, record storage on host, host dashboard, MCP-over-paired-host).
- `[MAC]`, `[LINUX]`, `[WIN]`, `[OMARCHY]` platform restriction. `[MAC]`/`[LINUX]`/`[OMARCHY]` lines are not needed for a Windows-first port but are kept so nothing is silently lost.
- Unmarked = port for Windows (and keep platform-neutral where Qt allows).

Doc short names: README, CONTRIB, CL (CHANGELOG, with version), WT (docs/walkthrough.md), AUTO (docs/automation.md), AGENT (docs/agent-api.md), MCP (docs/mcp.md), PERS (docs/personalize.md), MINT (docs/meeting-intelligence.md), MREV (docs/meeting-insight-review.md), PROF (docs/cleanup-profiles.md), BKP (docs/backup-restore.md), EXP (docs/export-support.md), GS (docs/guided-setup.md), SPEECH (docs/speech-models.md), NET (docs/network-and-privacy.md), HUPD (docs/host-updates.md), BETA (docs/beta-releases.md), REL (docs/reliability.md), RH (docs/release-health.md), LSA (docs/linux-system-audio.md), PREV (docs/preview-optimizations.md), TSFJ (docs/typesafe-fast-judgments.md), TSLS (docs/typesafe-live-state.md), TSEX (docs/typesafe-experiments.md), WSIGN (docs/windows-signing.md), DAUTO/DPERS (docs/design/automation|personalize/design.md), MW-code (menu code).

Cross-reference: what FioriVoce has today (about 3k lines) is the Parakeet engine wrapper, a CLI, and a one-window Qt app. Everything below is unchecked.
