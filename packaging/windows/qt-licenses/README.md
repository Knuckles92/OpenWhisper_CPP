# Qt license texts

The Windows preview uses QtBase and QtSvg. The `6.10.3` folder contains the distinct, unmodified license files from the two official source tags. Identically named files in both modules had identical Git blob hashes. The packaging script uses these copies when the binary kit omits its license files and its CMake version matches the source tag.

- [QtBase v6.10.3 license files](https://github.com/qt/qtbase/tree/v6.10.3/LICENSES)
- [QtSvg v6.10.3 license files](https://github.com/qt/qtsvg/tree/v6.10.3/LICENSES)
