## Qt 6

FioriVoce's windows, dialogs and icons are built with Qt 6 (Qt Core, Qt GUI, Qt Widgets, Qt SVG
and Qt Network, with the platform, style, image-format and TLS plug-ins that sit beside the
executable).
Qt is used under the GNU Lesser General Public License version 3 (LGPL-3.0); the Qt libraries
carry their own copyright notices and are the property of The Qt Company Ltd. and the other Qt
contributors.

Qt is linked dynamically. The Qt libraries are separate DLLs in the install folder, so a copy of
FioriVoce can run against a rebuilt Qt of the same version and the same compiler. The Qt source
code is available from <https://download.qt.io/official_releases/qt/> and <https://code.qt.io/>.
